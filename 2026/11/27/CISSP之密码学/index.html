CISSP--密码学

Posted on 2026-11-27

对称密码 / 非对称密码 / 哈希函数 / 数字签名 / 公钥基础设施 / 混合加密法 / 应用密码学。

密码基础

密码基本目标：保密性 + 完整性 + 身份认证 + 不可否认性

五元组：明文 [P] + 密文 [C] + 密钥 [K] + 加密 [E] + 解密 [D]

密钥：密钥大小由位大小（bit size）决定，范围从 0 ~ 2ⁿ（n 是位大小）。

逻辑运算

运算 规则 备注
与 (AND) 全真为真，一假即假
或 (OR) 一真即真，全假为假
非 (NOT) 取反 用 ~x 表示
异或 (XOR) 相同取假，相反取真
模运算 (MOD) 取余 例：8 mod 6 = 2

核心概念

  • nonce：用于取随机数。
  • 零知识证明：通过完成某个任务的方式，证明自己拥有口令或密码。
  • 分隔知识（权限分割）：例如 “N 取 M 控制”（8 取 3，即拥有权限的 8 个人中，任意 3 个在场即可取得密钥）。
  • 代价函数：衡量密码强度，代价函数值仅需略大于爆破时间值即可。

古典密码

移位密码

行作顺序，列作值：对 K 的字母顺序排序，将明文对齐 K 长度续写，最后将列按 K 的字母顺序合并。

替换密码

  1. 凯撒密码 (ROT3)：A+3 → D，B+3 → E，K = 1。
  2. 维吉尼亚密码（彩虹表）：C = (P + 3) mod 26，P 作行、K 作列，且 K 常为词或句。
  3. 单次密本：C = (P + K) mod 26，K 与 P 一样长，且只可使用一次（为明文消息中每一个字母使用不同的替换字母表）。

运动密钥密码（也称书密码）

K 与 P 一样长，K 常选自书 / 杂志等某句话。

例：明文 [RICH] + 密钥 [WITH]，二者取模 → 密文 [NQVO]。

块密码 vs 流密码

  • 块密码：在消息「块」上运算，例如移位密码。
  • 流密码：一次在消息或消息流的一个字符 / 位上进行，例如凯撒密码、单次密本。

混淆与扩散

例：某个算法先进行替换，再通过移位重新排列被替换字符的位置。

  • 替换的作用就是「混淆」；
  • 移位的作用就是「扩散」。

现代密码学

常用三类算法：对称加密 / 非对称加密 / 哈希算法。

1. 对称加密

  • K 相同，用于海量加密，只提供保密性安全服务。
  • 当 K 仅用作单次会话的短暂 K，此时 K 也称作临时 K。
  • 常见于传输层安全协议 TLS（临时 K 用于生成对称密码；非对称 K 用于生成加密信道）。
  • K 数量（n 为参与人数）：n(n-1)/2

弱点：

  1. K 分发（存在被攻击者获取的情况）；
  2. 对称 K 加密法不提供不可否认性（无法判断消息由谁发出）；
  3. K 缺乏可扩展性；
  4. K 经常重新生成。

2. 非对称加密

公 K（所有用户 & 公 K₁）+ 私 K（单个用户 & 私 K₁）。

保证消息由 Bob 发出：

  1. 创建消息摘要（哈希）；
  2. Bob 使用私 K 加密摘要；
  3. 其他用户用公 K 解密，并验证被解密消息摘要的准确性。

优点：

  1. 添加新用户只需生成一个公私 K 对；
  2. 便于非对称加密系统移除用户；
  3. 只需在用户私 K 失信时重新生成 K；
  4. 非对称加密 K 提供保密性 + 身份认证 + 不可否认性；
  5. K 分发简便易行；
  6. 无需预先建立通信关联。

弱点：运算速度慢。

3. 哈希算法

消息摘要，也叫哈希值 / 指纹。

4. 混合加密

安全传输大量数据时，先用公 K 建立连接，以此交换对称 K，再让剩余会话使用对称加密，这称之为混合加密。

密码类型

对称加密运行模式

模式 全称 / 说明 特点
电子密码本模式 [ECB] 不安全 每次处理一个 64 位块，只用选好的 K 给块加密（同 P 同 C），只交换少量数据
密码块链接模式 [CBC] Cipher Block Chaining 每个未加密块在加密前需借助上一密文块进行异或运算；解密需解密 C 并反向异或；初始向量（IV）需发送给 C 的接收者
密码反馈模式 [CFB] Cipher Feedback 针对实时生成数据运算（用与块大小相同的存储缓冲区）；缓冲区填满时才加密，将 C 发送给接收者，依次填满加密传输；与 CBC 相同使用 IV 和链接
输出反馈模式 [OFB] Output Feedback 与 CFB 类似，但不是对密文块异或，而是与种子异或；用初始化向量创建种子值，后续种子值用算法在前一种子值基础上运算得出；不存在链接函数，传播错误不会扩散
计数器模式 [CTR] Counter 与 CFB / OFB 类似的流密码，用简单计数器为每次运算增量
Galois/计数器模式 [GCM] Galois/Counter Mode CTR + 数据真实性控制（添加身份认证标记实现）
带 CBC-MAC 计数器模式 [CCM] Counter with CBC-MAC CTR + CBC-MAC（保证数据真实性的密码块链接消息验证码）
